Featured work

SkillSpring — Multi-tenant Enterprise LMS

Cognizant Internal Product · Feb 2023 – Present
Production

Internal enterprise Learning Management System replacing third-party tools like Udemy for Business. Serves multiple business units across Cognizant on a fully serverless AWS architecture with a micro-frontend UI.

  • Event-Driven Backend: 8+ Spring Boot 3 microservices on AWS Lambda, decoupled via Amazon EventBridge and SQS for cross-service orchestration.
  • DynamoDB Modeling: Designed GSIs, composite partition keys for multi-tenant isolation, and paginated queries (lastEvaluatedKey) across 6+ tables.
  • Performance: Caffeine in-memory caching (30-min TTL, 500-entry capacity) on high-traffic learner landing-page APIs to reduce DynamoDB read load.
  • Micro-frontend: 3-app architecture via Module Federation (Next.js + @module-federation/nextjs-mf) — Admin and Learner portals deploy independently with shared auth from a host shell.
  • Migration API: Paginated batch migration converting legacy course data into a new Assembly schema without downtime.
  • Security: AWS Cognito + Spring Security with JWT/OAuth2 for multi-tenant RBAC across system admin, super admin, content author, and learner roles.
  • Observability: Datadog APM + OpenTelemetry for distributed tracing across Lambda microservices.
  • CI/CD: Multi-stage AWS CodeBuild pipelines with BlackDuck, Checkmarx, SonarQube, and Prisma Cloud security scans.
